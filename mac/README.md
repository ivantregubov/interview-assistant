# Interview Assistant

Записывает экран с курсором и кликами, микрофон и звук системы, затем создаёт расшифровку диалога. Требуется macOS 26 или новее.

## Сборка

```
bash build.sh
```

Если нет Xcode Command Line Tools, скрипт откроет установщик. После установки запустите его ещё раз.
Скрипт закрывает старую версию, ставит новую в `~/Applications`, сбрасывает устаревшее разрешение и запускает приложение.
Разрешение на запись экрана после каждой сборки нужно включить заново: автоматически это делает только пользователь.

## Первый запуск

1. Разрешите доступ к микрофону.
2. Разрешите запись экрана в системных настройках и перезапустите приложение.

После включения разрешения нажмите в приложении «Перезапустить».

## Что получается

Каждая запись лежит в отдельной папке `~/Movies/Interview Assistant/<дата и время>/`:

| Файл | Содержимое |
| --- | --- |
| `screen.mov` | Видео до 1080p, 30 кадров в секунду; дорожка 1 микрофон, дорожка 2 звук системы |
| `mic.m4a` | Только микрофон, то есть вы |
| `system.m4a` | Только звук системы, то есть собеседник |
| `session.json` | Дата, длительность, устройства |
| `transcript.md` | Диалог «Интервьюер» и «Я» с метками времени |
| `transcript.json` | Тот же диалог с метками времени в секундах |

Все файлы начинаются в один момент, паузы заполнены тишиной. Поэтому `mic.m4a` и `system.m4a` можно расшифровать
по отдельности и объединить реплики по меткам времени, сразу зная, кто говорит.

## Расшифровка

Галочка «Расшифровка после записи» включена по умолчанию. После остановки записи приложение распознаёт обе дорожки
на этом Mac и сохраняет диалог в папку записи. При первом запуске macOS скачивает языковую модель, само аудио никуда
не отправляется. Готовый файл открывается автоматически. Кнопка «Расшифровать существующий файл» повторяет расшифровку
записи или обрабатывает любой аудио- и видеофайл. Папка для записей меняется на вкладке «Настройки».

## Подсказки во время записи

Для тренировочных интервью. На вкладке «Настройки» выберите DeepSeek или OpenRouter и добавьте API-ключ. Ключ хранится в
Связке ключей macOS. Во время записи приложение распознаёт речь на этом Mac и отправляет в выбранный сервис только текст.
На вкладке «Интервью» появляются вопросы, подсказки и оценка ответов, правильные отмечаются зелёной галочкой.
После остановки там же видны итоги, они сохраняются в `interview-report.md`.

## Советы

- Используйте наушники. С динамиками голос собеседника попадёт и в микрофон, и разделение реплик испортится.
- Перед важной записью сделайте тестовую на минуту и проверьте оба индикатора уровня.
- Приложение работает и из строки меню, а его окно в запись не попадает.
- Если приложение упадёт, `screen.mov` сохранится с точностью примерно до 10 секунд. Файлы `.m4a` в этом случае могут не открыться.
- Предупреждайте собеседника о записи: требования к согласию зависят от страны и правил компании.
